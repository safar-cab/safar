## Driver Recruitment

### Requirements
- Valid commercial driving license
- Clean driving record
- Smartphone with data plan
- Local references
- Know local routes (Indore + MP highways)

### Where to Find
- Existing taxi driver networks
- Auto driver associations
- Employment offices (Rozgar offices)
- Word of mouth
- Local newspaper classifieds

### Onboarding
1. Document verification (license, Aadhaar)
2. Background check (police verification)
3. Driving test (1-hour evaluation)
4. App training (2 hours)
5. Customer service training (1 hour)
6. Trial rides (3 supervised rides)

## Build vs Buy vs Outsource

| Area | Decision | Reasoning |
|------|----------|-----------|
| Core app | Build (you) | Core product, needs full control |
| GPS tracking | Build + Buy device | Custom integration, bought hardware |
| Payment | Buy (Razorpay) | Don't build payment infrastructure |
| SMS | Buy (MSG91) | Commodity service |
| Maps | Buy (Google Maps) | Best India data |
| Logo | Outsource (Fiverr) | One-time, not core skill |
| Legal docs | Outsource (lawyer) | Expertise needed |
| Accounting | Outsource (CA) | Compliance critical |
| Marketing content | Do yourself → outsource later | Budget constraint |
