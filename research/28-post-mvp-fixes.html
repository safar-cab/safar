Post-MVP Fixes & Enhancements

UI fixes, seed data, map integration, and States & Cities management — applied after completing all 5 MVP phases.

Replaced plain <select> with app's custom <Select> component for consistent dropdown styling across admin panel.

Seed Data — Notifications (40 records)
SEED
  • 15 customer notifications — booking confirmations, ride updates, cancellations

4
Admin Live Rides — Map & Details
ENHANCE
  • Click ride card → side panel with map + full details
  • Google Maps Static API integration (with VITE_GOOGLE_MAPS_KEY)
  • Fallback: coordinate display + "Open in Google Maps" link
  • Split layout: ride list (left) + map panel (right)
  • Driver + customer contact info with phone call links
  • Real-time position updates via WebSocket
5
States & Cities Management
NEW FEATURE

Backend:

  • geo.schema.ts — State (name, code, isActive) + City (name, state ref, isActive)
  • LocationsModule — service, controllers (public + admin)
  • Enable/disable state cascades to all its cities
  • Delete state blocked if cities exist
  • Route enable/disable endpoint
  • Public API for customer booking form city selection

Frontend:

  • StatesAndCities.tsx — full admin management page
  • Expandable state cards with nested city list
  • Add/delete states with state code
  • Add/delete cities per state
  • Toggle enable/disable for states and cities
  • Stats cards (total/active counts)
  • Admin sidebar: "States & Cities" nav item

Seed Data:

  • 5 states: MP, RJ, GJ, MH, UP (UP disabled)
  • 27 cities across all states
  • UP cities auto-disabled with state
